## 0. 新增基础设施知识(重要)

### 0.1 scidown 验证码可完全绕过
`verify.php`(顶象滑块)的 JS 混淆解开后核心一行:
```
yztoken = md5("1sciq" + ztime + "1")     # ztime = 十位秒级时间戳
```
Cookie 三件套 `yztime=<unix秒>; yzcount=1; yztoken=<上面md5>`,有效期 600 秒。
更稳的免验证通道:先 `GET /lxapp.php?lx=<任意值>`,响应会 Set-Cookie 这三件。
之后 `GET /scixue.php?doi=<DOI>` 直接 200(带登录 cookie + Referer)。

### 0.2 scixue.php 是纯服务端渲染,没有"异步轮询"
- 已登录 + yz 三件套才出结果;**还必须带 `dlzt` cookie**(登录时间戳,漏了会 `Undefined index: dlzt`,解析结果为空)。
- 解析结果在 `<input id="uname" name="a" value="<最终URL>">`:
  - `zy9/bban 直链` → 有缓存,直接下;
  - `http://share.scifree.shop/zxwileyq.php?doi=<DOI>?download=true&auth_key=<now+300>-0-0-<md5>` → **Wiley 系无缓存的实时机构代理**,签名 5 分钟有效;
  - `https://doi.org/<DOI>` → 完全没辙的回落。
- Elsevier 系无缓存没有对应代理(实测回落 doi.org)。
- "取回本地"表单 POST 到 `http://down.sciokk.cn/sci/down1.php?<每次变的8位hex>`,字段 `a=<uname URL>`;
  响应是等待页,其 JS 把浏览器再跳到 a= 的 URL(对 Wiley 即 zxwileyq 演示页)。
- 副产品:每次成功 scixue 解析会自动在网盘 console.php 登记"离线文件"(3000KB 占位)。

### 0.3 Wiley 机构共享认证链(拿下 Wiley 无缓存文献的正路)
1. 浏览器里走完 `lxapp → scixue`,点「取回本地」(表单 POST down1.php)。
2. 落到 `share.scifree.shop/zxwileyq.php` 演示页 → 页面表单 POST 到
   `https://onlinelibrary.wiley.com/action/authenticateSharedSP`(SharedSP 机构共享,**无需账号**)。
3. 认证完成后,浏览器在同源页面里 `fetch('/doi/pdfdirect/<DOI>', {credentials:'include'})`
   → 200 + `%PDF` 字节流(未认证时同一请求是 403)。直接 base64 分片搬回本地。
   注意:`/doi/pdf` 与 `/doi/epdf` 只是壳页;IAB/Electron 的原生下载事件会被 Playwright
   拦截并取消,**别指望落盘,用同源 fetch 搬字节**。

### 0.4 Sci-Hub 镜像簇与机器人墙
- `sci-hub.ru` → 自动 302 到 `sci-hub.jp`;*.ru/.jp 有 "Are you a robot?" 页,页面只有一个
  "No" 文本节点,点它即过(纯 JS 挑战,无验证码)。
- `sci-hub.ee` / `sci-hub.ren`:Cloudflare **Turnstile** 复选框,真浏览器点一下即过
  (IAB 里用 cua.click 打坐标,复选框约在 (510,256) @1280x720)。
- 存储直链模式:`https://sci-hub.jp/storage/<y>/<n>/<hash>/<name>.pdf`、
  `https://sci-hub.red/storage/moscow/<n>/<hash>/<name>.pdf` — curl 可直下(带 Referer)。
- `sci-hub.st`:证书全球坏死(ERR_CERT_AUTHORITY_INVALID,jina.ai 境外浏览器同样报错),
  且屏蔽数据中心 IP(Archive.org SPN 爬虫 403、codetabs/allorigins 代理全灭)。真人浏览器
  点"高级→继续前往"可下。**唯一已知正确拷贝会藏在这种站点上**(如 /uptodate/<Elsevier PII>.pdf)。
- `pdf.bban.top/<DOI>.pdf` 是 bban 的另一个前缀(sci-hub.ee 系代理在用),与
  `sci.bban.top/pdf/<DOI>.pdf` 不同源,探测缓存时两个都要试。

### 0.5 区块国家劫的出版社:Wayback Machine 是正解
EKB(埃及 ejz.journals.ekb.eg)整域被墙(浏览器/curl 全 000)。但 Wayback 常年有抓:
```
web.archive.org/cdx/search/cdx?url=<host>/<path 前缀*>&output=text   # 先查有没有
web.archive.org/web/<timestamp>id_/<原始URL>                          # id_=取原始字节
```
本例 203 直接命中 2022-06-16 的官方 PDF 存档。**PDF 类内容查 CDX 时记得用 `id_` 取原文件。**

### 0.6 印度 NOPR 仓库改域名了
老域名 `nopr.niscair.res.in` 已死;新域名 **`nopr.niscpr.res.in`**(NIScPR)。
IJEB 等刊全文 bitstream 直链:`/bitstream/123456789/<id>/1/IJEB%20<卷>(<期>)%20<起页>-<止页>.pdf`。
用 Bing 搜 `"<标题片段>"` 找 bitstream 链接最快(Bing 重定向 `u=a1<base64url>` 解码即真链)。

### 0.7 搜索引擎现状(该网络环境)
- Google Scholar:IP 不一致风控(代理),基本不可用。
- Bing:时好时坏,代理污染时会返回完全无关结果(搜索"包跟踪"广告),别信单次结果。
- DuckDuckGo html 版:间歇被墙。
- **Crossref/OpenAlex/EuropePMC API 全程可用**,是拿元数据/作者/PII 的可靠底座;
  OpenAlex 的 `open_access.oa_status=bronze` + Wiley SharedSP 链 = Wiley 系万能钥匙。

### 0.8 scidown 网盘(lxgo/lxgodown)真相
- `lxgo.php?lx=<URL>` 云链解析:对 `92.223.124.29/*.opjc` 走 lxapp 短路;普通 URL 给 lxgodown。
- `lxgodown.php?lx=<URL>`:异步任务页 60s 自刷新,**实测对普通 URL 永远停在"转存中"**,
  属于半装饰品;别把希望放在它身上。
- 网盘「离线下载大陆」(nlxdown.php)是纯前端假进度(存 localStorage)。
- 「文件秒传秒下」是纯本地 IndexedDB,没有在线库。
- 网盘登录验证码为 3 位数字图片(如 982),canvas 导出可自读。
