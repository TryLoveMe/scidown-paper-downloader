# 机制分析:open-access.shop / Scidown 生态完整逆向(协议级)

> 2026-08-30 全链路实测还原。所有 URL/字段/行为均来自真实响应。
> 网站随时可能改版,本节结论以"当次实测"为准;改版后按页面新特征重新归纳。

## 0. 30 秒总览

```
open-access.shop(检索, 区域封锁提示) → 唯一活路 = Scidown cloud drive
  → scidown.cn/lx.php?lx=http://92.223.124.29/<关键词>.opjc      (提货凭证, .opjc 是空文件)
      → 302 → lxapp.php?lx=<url>                                 (下发 yz 免验证 cookie 三件套)
          → JS 跳 scixue.php?doi=<DOI>                           (核心解析页, 服务端同步渲染!)
              → <input id="uname" name="a" value="<最终直链>">
                  → 按文献类型给不同后端(bban/zy9/zdwe/lanzou/scifree-Wiley/doi.org 回落)
                  → POST down.sciokk.cn/sci/down1.php?<8hex> (字段 a=<直链>)= "取回本地"
                      → 缓存命中: 直接回 PDF 字节流
                      → Wiley 未缓存: 回等待页 → JS 跳 zxwileyq 演示页 → SharedSP 机构认证 → 官方 PDF
```

**最关键的事实(决定一切打法):**
1. `scixue.php` 是**纯服务端渲染**——没有"提交抓取任务→轮询"的异步机制(全站不存在 dlas/vef-cj/cj/api 等任务端点,全部 404)。解析结果是页面渲染时就确定的。
2. `bban`/`zy9` 直链是**固定模式**,可绕过整套登录/验证直接构造。
3. 无缓存 Elsevier 系:解析回落 `https://doi.org/<DOI>` = 主站无货。无缓存 Wiley 系:`share.scifree.shop/zxwileyq.php` 实时代理(5 分钟签名),配合 Wiley SharedSP 机构共享认证可拿官方原版 PDF。
4. 顶象验证码可**直接计算绕过**(见 §3.3)。

## 1. open-access.shop(检索前端)

- 搜索:`GET https://www.open-access.shop/?doi=<DOI>`;搜索框接受 DOI/标题/作者/参考文献。
- 结果页给两条资源行:
  - `open uconn resources` → `?w2=<DOI>`(UConn 侧);
  - `open access resources` → `?w=<DOI>`。
  - 每行一个 `Download` 按钮(类名 `.sd-button`)→ 打开 `sd-modal` "Choose download method"。
- 弹窗四项(实测):
  | 选项 | 链接 | 实测 |
  |---|---|---|
  | Scidown cloud drive | `https://www.scidown.cn/lx.php?lx=http://92.223.124.29/<关键词>.opjc` | **唯一活路** |
  | Lool Download | `pan.epicgames.com/?pan=<url>` | 连接被重置 |
  | Bitta Download | `www.beatport.com/?bpan=<url>` | 真音乐站,参数无意义 |
  | Yutupo Download | `open-access.shop/?w=<url>` | 只回显首页 |
- **区域封锁**:本网络环境访问 shop 或源站 `92.223.124.29` 时,页面弹 Warning"Access is not supported in your region, please change your IP or choose the download method on the right.";curl 直接连 92.223.124.29 为 connection refused。→ 这两层由**境外中转**(down.sciokk.cn)化解,本地脚本**不能**直连 92.223.124.29。
- 与 scidown 的 cookie 无关;lx.php 由 shop 页面用 `target="_blank"` 打开。

## 2. scidown.cn 解析链(核心)

### 2.1 lx.php —— 提货凭证接入
- URL:`https://www.scidown.cn/lx.php?lx=<urlencode(http://92.223.124.29/<key>.opjc)>`
  - `<key>` = open-access.shop 的检索词,通常就是 DOI(大小写按原样)。
- 行为:
  - 未确认过协议 → 200 中转确认页(勾选 `tosCheck` 后 `confirmDownload()` 置 cookie `download_agreed=1`);
  - 已带 `download_agreed=1` → **302** `Location: lxapp.php?lx=<原样>`。
- 响应特征:无 `download_agreed` 时页面含"中转下载确认 - 安全通道"文案。

### 2.2 lxapp.php —— 免验证入口(★★ 关键 shortcut)
- URL:`GET https://www.scidown.cn/lxapp.php?lx=<url>`(只认 `lx` 参数;`lxapp.php?doi=` 会 PHP Notice `Undefined index: lx`,跳空 doi)。
- 响应 430-442 字节 HTML,核心:
  ```html
  <title>Scidown网盘离线页面</title>
  ...
  function jump(){window.location.href='/scixue.php?doi=10.1111/jpn.13877';}
  setTimeout(jump,500);
  ```
  DOI 从 lx 参数内提取(即 `<key>.opjc` 的 key)。
- **同时 Set-Cookie:`yztime=<unix秒>; yzcount=1; yztoken=<md5>`,有效期 600 秒** —— 这就是人机验证的免验证通道:拿到这三件后直访 scixue.php 不再弹顶象滑块。**没有 yz 三件套直接访问 scixue.php 会 302 到 verify.php。**
- 引用 `/xz/js/jiazai.js`:仅 loading 遮罩"正在离线到网盘,请稍后",无逻辑。

### 2.3 verify.php —— 顶象滑块(可绕过)
- 特征:标题"安全防护系统",引入 `/xz/js/md5.js` + 顶象 appId `63b9b8e806e24dec8fb044a5f9a68e67`。
- **绕过公式(jsjiami v6 混淆解出,3 个样本全部 MATCH):**
  ```python
  import time, hashlib
  ztime = int(time.time())                      # 十位秒级时间戳
  yztoken = hashlib.md5(f"1sciq{ztime}1".encode()).hexdigest()
  cookies = {"yztime": str(ztime), "yzcount": "1", "yztoken": yztoken}  # 600s 有效
  ```
  于是:先 `GET /lxapp.php?lx=<任意值>` 收 Set-Cookie(更稳),或自算三件套,两者等价。
- 滑块本体(拖动还原)服务端校验轨迹,自动化风险高 → 能绕过就不要碰滑块。

### 2.4 scixue.php —— 解析结果页(纯服务端渲染)
- URL:`GET https://www.scidown.cn/scixue.php?doi=<DOI>`
- 访问条件(**全部满足才出结果**):
  1. yz 三件套 cookie(否则 302 verify.php);
  2. 登录 cookie:**`dlzt` 必不可少**——漏了页面正文出现 PHP Notice `Undefined index: dlzt in scicook.php on line 25` 且 `#uname` 为空(这是最隐蔽的坑,见过把它当"未收录"误判的);
  3. 带 Referer(如 `/lxapp.php?...` 或 `/lx.php?...`),否则返回 340B"友情提醒:请求信息有误,请联系管理员或者换其他浏览器使用"。
- 响应(200,"临时取回页面"):
  ```html
  <input class="input" type="text" value="<论文标题或 www.scidown.cn 占位>">   <!-- 有缓存时填标题 -->
  <input type="hidden" name="a" id="uname" value="<解析结果URL>"/>             <!-- ★ 核心结果 -->
  <form action="http://down.sciokk.cn/sci/down1.php?<每次变化的8位hex>" method="post" target="_blank">
    <input type="hidden" name="a" value="<同 uname>"/>
    <input type="submit" value="取回本地"/>
  </form>
  <form action="http://down.sciokk.cn/sci/down.php?<8位hex>">...</form>  <!-- 网盘预览(read.php) -->
  ```
- `#uname` 的 value 按文献类型(实测枚举):
  | value 模式 | 含义 | 后续 |
  |---|---|---|
  | `http://zy9.xeak.top/pdf/<DOI>.pdf` | 缓存命中(主线路) | curl/浏览器下载(CF) |
  | `https://sci.bban.top/pdf/<DOI>.pdf?download=true` | 缓存命中(分流) | 脚本直接下 ★ |
  | `http://zdwe.sciokk.cn/https/<hex>/content/pdf/<DOI>.pdf?auth_key=<epoch>-0-0-<md5>` | 机构代理网关 | curl 可下,~1h 签名 |
  | `https://gosci.lanzouq.com/<id>` | 蓝奏云 | 浏览器二次点击 |
  | `http://share.scifree.shop/zxwileyq.php?doi=<DOI>?download=true&auth_key=<now+300>-0-0-<md5>` | Wiley 实时代理 | 走 SharedSP 链(§2.6) |
  | `https://doi.org/<DOI>` | 主站无缓存(Elsevier 系常见回落) | 主站放弃,转离线源 |
  | ``(空) | IP 被降级 或 未收录且非 Wiley | 停手/换路 |
- **"打开"按钮无 href(死按钮)**;"相关内容1-5"是服务端直出模板(sci-hub.ru/DOI、doi.org/DOI、百度/必应/PubMed 搜索链接)。
- 页面脚本只有 baidu push.js 与 Tidio 客服,无轮询、无 AJAX。

### 2.5 down.sciokk.cn "取回本地"(回传引擎)
- `POST http://down.sciokk.cn/sci/down1.php?<8hex>`(token 每次请求都变,8 位 hex),字段 `a=<uname URL>`,需 UA 带 **"QIHU 360SE"** 后缀(否则被 UA 白名单拒)。
- 三种响应:
  1. **缓存命中** → 直接回 PDF 字节流;
  2. **Wiley 型** → 865B HTML 等待页"正在从网盘中取回本地,请您耐心等待!"含 `<script>window.location.href="<zxwileyq 签名地址>";</script>`;
  3. **解析不出** → 提示跳"期刊官网"(即 value 本为 doi.org 的)。
- down.php(网盘预览)→ read.php,同样包 iframe 直链,无独立代理作用。

### 2.6 Wiley 实时代理链(★ 无缓存 Wiley 文献的正解)
1. scixue 解析出 `auth_key=<now+300>-0-0-<md5>`(5 分钟时效,每次解析实时重签)。
2. POST down1.php(a=该地址)→ 等待页 → JS 跳到 `share.scifree.shop/zxwileyq.php?...`。
   - 直接 GET 该地址无 Referer/无前置链 → "友情提醒:请求信息有误"(Referer 校验)。
3. zxwileyq 页(14KB,"Operation step demonstration","The following information is provided by netizens"):
   ```
   Step 1: Click Login → <form id="asder" method="post" action="https://onlinelibrary.wiley.com/action/authenticateSharedSP" target="_blank">
   Step 2: Enter → 文献页链接 / a "get pdf" 链接
   ```
4. POST `authenticateSharedSP`(**共享机构凭证,无需账号**)→ Wiley 登录态建立。
5. 同源 `fetch('https://onlinelibrary.wiley.com/doi/pdfdirect/<DOI>', {credentials:'include'})` → **200 + `%PDF` 字节流**(实测 1.94MB,原版排版)。认证前同请求 403。
   - `/doi/pdf` 与 `/doi/epdf` 只是 HTML 壳页(epdf 会 302 回 abs),**真正的字节在 pdfdirect**。
   - 浏览器 IAB/Electron 原生下载事件会被 Playwright 拦截取消 → **不要等落盘,用页面内 fetch → base64 分片搬出**(见 docs/05)。

### 2.7 lxgo.php / lxgodown.php(网盘"云链"系统,有坑)
- `lxgo.php?lx=<URL>`:云链解析页("CloudLink"),支持 HTTP/HTTPS/Magnet/Ed2k:
  - `.opjc`(92.223.124.29)左值 → "文档资源已就绪" + `/lxapp.php?lx=` 按钮(秒级短路);
  - 普通 URL → 结果卡 + `立即下载 / 打开链接` → `lxgodown.php?lx=<原URL>` + `复制链接`(onclick copyToClipboard)。
- `lxgodown.php?lx=<URL>`:"云端离线下载中心",60s 自动刷新,任务写 **IndexedDB**(`saveRecord(url,"","pending")`)——**实测普通 URL 永远停在"转存中",属半装饰品**;不要用它当主通道。真实回传永远走 down.sciokk.cn。
- `wangpan/nlxdown.php`(离线下载大陆)与 `wpnew.php`(文件秒传秒下):解混淆后 **fetch=0 XHR=0**——纯前端假进度(localStorage downloadTasks)/纯本地 IndexedDB(CloudDriveDB),没有任何在线库。

### 2.8 serpaper.php —— 新版检索 SPA(SciDownScholar Pro)
- 纯客户端 SPA(jsjiami.com v7 混淆,145KB bundle);检索 fetch PubMed/CrossRef 公开 API;**下载按钮全部是外链**(官网/Bing/百度/Scihub/海外OA=open-access.shop/OpenAccess=open-accessk.xyz/文献递送=helpcreat.php/多馆际互借=helpall.php)。
- 广告卡由 `adgd.js`/`adtc.js` 随机注入(146 个工具,"SciDown学业计划"只是其中一条 → /suggest/kilemater.php,实测为免费打卡小工具,无价格无权益)。
- 站内检索计数 cookie:`searchdl` / `searchtimes`。
- 结论:SPA 无下载 API,别在它身上花时间逆向。

## 5. 校验纪律(下载成功与否的唯一标准)

1. PDF 字节以 `%PDF` 开头(前 1KB 内);
2. 大小 > 10KB(错误页多为 400B-6KB HTML);
3. `pdftotext` 前两页与期望题名做词命中:取题名前 8 个 ≥3 字母词,**转小写**后比对,命中 ≥60% 才通过(大小写坑见过一次:漏 `.lower()` 会把正确的文章判成 2/8,还把 #76 错配成 #17);
4. 可加验:PDF 首页文本里 `DOI: 10.xxxx/...` 是否与目标 DOI 一致(出版社元数据 `/Title` 常被标错,勿信);
5. 文件名不可信(下载下来可能是 21935.pdf / S0041...pdf 之类),**只认题名核对**。
