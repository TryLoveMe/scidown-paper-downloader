# 机制分析:open-access.shop / Scidown 生态完全逆向

> 2026-08-30 实测还原。网站随时可能改版,以实测为准。

## 2. 各后端细节

### 2.1 bban(分流线路2)★ 脚本首选
- `https://sci.bban.top/pdf/{DOI}.pdf?download=true`
- 无登录、无验证码、无 CF。requests/curl 均可。
- 未收录返回 nginx 404(548B HTML)。**可用作存在性探测**。
- 地址模式固定 → 不经 scidown 直接构造。

### 2.2 zy9(主线路1)
- `http://zy9.xeak.top/pdf/{DOI}.pdf`(解析结果里斜杠可能呈 `%252F` 双重编码,三种编码形态同一文件)
- Cloudflare 防护:python-requests 必被 403(5981-6104B 挑战页);curl 引擎偶尔可过;
  真浏览器自动过 JS 挑战。
- 地址模式固定 → 可直接构造给人工浏览器。

### 2.3 zdwe(机构代理网关)★ 未收录文献的正解
- `http://zdwe.sciokk.cn/https/<hex>/content/pdf/{DOI}.pdf?auth_key=<epoch>-0-0-<md5>`
- hex 解码为 `wrdvpnisthebest!...` —— WebVPN(锐捷)固定网关标识,所有文献相同。
- **无 Cloudflare**,curl 带 UA + Referer 即可下载。
- auth_key 为时间戳签名,有效期约 1 小时,**每次解析重新生成,不可伪造**。
- 获取它必须:登录态 + lx.php 会话链 + scixue.php。

### 2.4 蓝奏云
- `https://gosci.lanzouq.com/<id>` → 文件页(标题即文件名)→ iframe 里「电信/联通/普通下载」
- 直链指向 developer2.lanrar.com,带一次性加密参数,且常见"网络异常需验证"页
  (POST ajax.php file/el/sign 换真链,参数与会话绑定)。
- **脚本难以自动化**,交人工浏览器一次点击即可。

## 3. 登录体系

- 登录页 `wangpan/login.php`:用户名 + 密码 + 图形验证码(`wangpan/999.jpg`,4 位彩色扭曲)。
- 会话极短(实测 ~30 分钟),过期后 scixue 又变回 login.php 表单。
- 勾选记住密码后 cookie 含明文账号:`dlus=<用户名>; dlps=<密码>`。
- 无 httpOnly,`document.cookie` 可整体导出 → 可移植到脚本。

## 4. 风控体系(顶象 DingXiang)

- 触发条件:短窗口内对 scidown 的高频请求(实测 ~10 次/分钟级别即触发)。
- 表现:跳 `verify.php` "安全防护系统",点「继续访问」弹滑块(`myCaptcha.show()`)。
- 滑块为"拖动还原图片"型,顶象服务端校验轨迹,自动化成功率极低 → **人工拖**。
- 严重时的**静默降级**:scixue 正常返回但 `a=""`(不报错!)——看到空解析就该停手。
- 页面自述:"如果您经常出现这个页面,可能您的 IP 存在问题"。
- 相关 cookie:`yztime/yzcount/yztoken`。每次过滑块后有短暂信任窗口(实测约 2-3 次解析)。

## 5. 网盘(附属系统,勿依赖)

- `wangpan/index.php`:登录后可用,有「离线文件」列表。
- 取回本地时服务器会注册离线抓取,文件会出现在列表里(如 3000KB),但
  `downno()` 点「下载」只 alert "网盘文件已过期" —— **临时缓存,不可作为下载来源**。
- 网盘另有「离线下载」(磁力/http 服务器代抓)与「文件秒传秒下」,额度有限。

## 6. open-access.shop 弹窗其余选项

- Lool(pan.epicgames.com):连接直接被重置,死链。
- Bitta(www.beatport.com):真·音乐网站,参数无意义,CF 拦截。
- Yutupo(/?w=<url>):只回显首页,无下载逻辑。
→ **只有 Scidown cloud drive 一条活路。**

## 7. 校验要点

1. `%PDF` 魔数 + >10KB —— 错误页通常是 400B-6KB 的 HTML。
2. pdftotext 前两页与标题做词命中(前 8 个 ≥3 字母词,命中 ≥60%)。
3. PDF 内嵌 DOI 可复核(`/Title` 元数据常被出版社标错,勿信)。
4. 下载文件名不可信(常见 21935.pdf 之类),只认题名核对。
